# 恒久署名資材の引き渡し準備

状態: HANDOFF_READY / GitHub Repository Secretsへの手動登録待ち。
生成した恒久鍵は1個。RSA 4096 bit、PKCS12、SHA256withRSA、有効期間10000日。
秘密鍵・パスワード・Base64値・Secret alias値はこのrepositoryへ保存していない。

引き渡しパッケージに含むもの:

- permanent-signing.p12
- GITHUB-SECRETS-HANDOFF.txt（必要な5項目の実値）
- RECOVERY-INSTRUCTIONS.md
- PUBLIC-FINGERPRINTS.json（公開certificateとkeystoreのSHA256）

引き渡しファイルは本人向け非公開ファイルとして永続保存し、保存先から
ZIP全体を復元した。元ファイルとのSHA256一致、5項目の過不足なし、
Base64復元とPKCS12実体の一致、正式keytoolによるcertificate一致、
秘密鍵による署名・公開鍵による検証、誤パスワードでの復号拒否を確認した。
復元確認で新鍵は生成していない。通常ログやActions artifactへ秘密値を出していない。

保全記録のencryptedArchiveSha256は、暗号化された秘密鍵を含むPKCS12
ファイルのSHA256を指す。ZIP自体は暗号化されていないため、そのアクセスは
本人向けに限定した。復元記録は本人向け永続ファイルの往復確認であり、
ユーザーの独立したoffline backupを実施済みと主張するものではない。
長期保管・独立backupの手順は引き渡し内のRECOVERY-INSTRUCTIONS.mdに収めた。
