# Pinned inventory → Drawing IR adapter V1

Status: ISOLATED_ADAPTER_ACCOUNTING_IMPLEMENTED / SOURCE_TO_IR_PRODUCT_CONNECTION_BLOCKED.

IR is the exact immutable candidate.1 from Track A at 3e1f6892ff5c6b06644b07b8247ccd9053b978db. The schema/validator/version bytes are selectively imported unchanged; no merge or contract revision. Source inventory reader and all Round2 evidence/tests remain unchanged.

`inventoryToDrawingIR(inventory, {DOMParser})` returns `{document, nativeSource, manifest, validation, productGate}`. `document` is validated with the pinned validator. `nativeSource` is a deep copy of the entire source inventory, preserving source keys, part/package hashes, native XML, EMU lexemes, text runs/paragraphs/br, component ledger and native group affine chain. `manifest.parts` binds each source object wrapper and each component to one IR inventory/ledger row. Wrapper/geometry/text identities are distinct. Wrapper role is retained in the manifest; geometry and text get independent DRAWABLE_PART rows, with original containers identified as CONTAINER.

The all-source geometry/text denominators are captured before deciding capability. Unsupported/Human-check items always have reasons and next actions. Backgrounds/hidden items require an explicit policy and are not silently deleted or implicitly excluded. A caller that deletes source before inventory cannot be certified by self-accounting: independent source→IR inspection remains mandatory.

Source object-local EMU geometries flow through path normalization, innermost local then outer parent affine matrices, slide EMU, layout MM y-down, and separate page CAD layout MM y-up. 36000 EMU = 1 layout MM; the y reversal translates by page height and is reversible. Page identities/order remain distinct. UNSCALED and empty calibrations remain unchanged. This does not assert real-world dimensions.

Supported geometry candidates: lines, rectangle four-corner polygons, single open/closed custom paths with integer source vertices, circles and ellipses under similarity transforms. Every vertex and native/basis vector is retained. Nonuniform rotated Office group semantics remain Human-check; nonsimilarity/skew ellipse, compound paths, curves and odd-EMU radii that candidate.1 cannot express without precision loss are explicitly blocked. A basis-vector orientation is recorded as such, never inferred from a bounding-box diagonal or claimed as a rigid rotation of shear.

`nativeNumbers` contains canonical numbers of constructed local IR geometry (zero vertices, source extents/path points, derived centers/radii). It does not prove literal original lexical retention. `manifest.geometryCandidates[].sourceNumberLexemes` preserves original signed/zero-padded source strings separately; raw XML/xfrm and the complete original inventory preserve them for unsupported items too. Candidate.1's numeric grammar rejects leading `+`/zero padding, so raw literal strings cannot occupy its nativeNumbers.lexeme unchanged.

Drawable objects are emitted only when mandatory candidate.1 style fields are explicitly resolved: native direct RGB/noFill, explicit integer line width, explicit equal paint alpha, explicit solid preset dash, with no unresolved paint/decorations/effects. Alpha is the explicitly supplied val / 100000, never an absent-alpha default. Stroke/fill absence is represented only by native noFill. Unresolved theme colors/font/anchor/baseline/layout, missing dash/opacity or mixed paint alpha are `CONTRACT_CAPABILITY_LIMITATION_*`. No guessed black, width 0, opacity 1, font, text size or anchor is inserted. Text remains native structured evidence with an explicit ledger block; dimension-like text is never promoted to a dimension.

Geometrically resolved components with unresolved mandatory style remain in `manifest.geometryCandidates` with layout coordinates and original native data. This is partial evidence retention, not a drawable IR object, not source→IR product readiness, and not DXF output. All four fixed G source packages currently emit zero drawable IR geometry. Exact counts are recorded in SOURCE-RETENTION-SUMMARY-V1.json. Positive tests exercise directly resolved primitive output under explicit style so this limitation cannot masquerade as successful conversion of real packages.

No exportEvaluations or target entities are generated. DXF, real Jw_cad, app UI and product Gate remain HOLD/NOT_RUN.
